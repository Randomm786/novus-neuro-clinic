MY NEURO HEALTH — PHASE 2 CLEAN REISSUE

This is a clean rebuild intended to replace the entire existing GitHub Pages website.

UPLOAD
1. Delete the old website files from the repository (keep the repository itself).
2. Extract this ZIP on your computer.
3. Upload the CONTENTS of this folder to the repository root.
4. Confirm index.html, CNAME, robots.txt, sitemap.xml and the assets folder are at the root.
5. Commit to main.
6. GitHub Settings > Pages should publish from main / (root).
7. Custom domain should be myneurohealth.co.uk.

DO NOT change your IONOS DNS if it is already pointing correctly to GitHub Pages.
